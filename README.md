# Lobito · K-9 Tactical Companion

[![GitHub Pages](https://github.com/tzayadet/Lobito/actions/workflows/jekyll-gh-pages.yml/badge.svg)](https://github.com/tzayadet/Lobito/actions/workflows/jekyll-gh-pages.yml)

Experimento interactivo de mascota virtual canina presentado como una unidad K-9. La interfaz utiliza un lienzo Canvas y un HUD para mostrar sus necesidades y estado.

**Demo:** https://tzayadet.github.io/Lobito/  
**Código:** https://github.com/tzayadet/Lobito

## Funcionalidades

- Indicadores de hambre, energía, moral, higiene y experiencia.
- Acciones de alimentación, juego, interacción y baño.
- Representación animada mediante Canvas.
- Registro visual de actividad y cambios de estado.
- Interfaz adaptable con estética de panel táctico.

## Ejecución

Aplicación estática de navegador. Abre `index.html` o utiliza la demo publicada en GitHub Pages. No necesita backend ni instalación.

El estado de la mascota se mantiene durante la ejecución actual y puede reiniciarse al recargar la página; esta versión no implementa guardado persistente.

## Tecnologías

- HTML5
- CSS3
- JavaScript
- Canvas 2D

## Alcance

Proyecto experimental y lúdico. No está conectado a dispositivos, sensores ni sistemas de seguimiento reales.
